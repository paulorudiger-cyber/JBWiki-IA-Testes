# 09001 - Notificações do Sistema

Serviço de notificações para avisos, atualizações de sistemas ou informativos destinados ao usuário JB Network, originados da JB Software.

# 1. Entendendo o formulário

- Visando a transparência na comunicação com os usuários do JB Network, desenvolvemos um sistema de alerta de notificações que será aberto automaticamente sempre que houver novas notificações urgentes.

No caso de outros tipos de notificações, elas podem ser visualizadas ao clicar no ícone de "Sino", que abrirá o formulário "09001 - Notificações do sistema".

# 3. Leitura e confirmação da notificação

- Para ler uma notificação, acesse a aba "Novas Mensagens" e clique na seta para expandir o conteúdo.

- Ao abrir o conteúdo da notificação, a confirmação de leitura é realizada automaticamente pelo sistema.

Essa regra faz parte do protocolo de monitoramento da JB Software para garantir a confiabilidade dos dados de leitura, sendo uma funcionalidade permanente do sistema.

# 5. Notificação urgente

- Notificações urgentes são de leitura obrigatória. Portanto, enquanto a leitura não for confirmada, o acesso ao sistema permanecerá bloqueado.

Este tratamento diferencia-se pela necessidade de evitar prejuízos ao cliente, seja por adequações legais ou necessidades técnicas imediatas.

Vale ressaltar que este tipo de notificação é utilizado apenas em casos críticos.

Quando uma notificação for urgente, o formulário será aberto automaticamente ao acessar o sistema, bloqueando as demais funcionalidades até que a mensagem seja visualizada.
