# 1. 1° Passo: Cadastro do usuário

- O cadastro básico nas aplicações web da JB Software começa com o registro do usuário (pessoa física ou jurídica). Sendo assim, o primeiro passo para acessar o JB Network é realizar o cadastro pessoal.

Para isso, o usuário ou seu gestor deve acessar o site www.jbsoft.com.br (sem estar logado no sistema) e clicar na opção "Acessar", localizada no canto superior direito da página:



O usuário será redirecionado para a página de login do JB Network e então deverá clicar na opção "Me cadastrar":



O usuário será redirecionado para a página de cadastro. Então, basta preencher os dados solicitados. Para mais orientações de como preencher, clique aqui.

IMPORTANTE: Atenção redobrada com Nome, Apelido e CPF. Preencha essas informações corretamente com os dados da própria pessoa. Eles compõem a chave única de acesso e são a base para a geração de senhas das aplicações. Lembre-se: após salvos, esses campos só poderão ser alterados pela JB Software - Matriz.

Certifique-se de que o e-mail informado esteja correto, pois uma mensagem será enviada para a validação da conta. Se o endereço cadastrado estiver errado ou for inexistente, a correção só poderá ser feita entrando em contato com a Franquia que atende o seu contrato ou, no caso de perfil público, com o setor comercial da JB Software.

# 2. 2° Passo: Cadastro do colaborador

- Após o cadastro do usuário, o sistema enviará um e-mail para a verificação de identidade. Com a conta confirmada, o usuário já conseguirá fazer login no JB Network, mas terá acesso a recursos limitados, pois seu perfil constará como público e ainda não possui nenhum vínculo de colaboração com empresas dentro do sistema.

Para liberar o acesso às ferramentas — como JB Comunica, Meu Painel (app), JB Obrigação, JB Ged, JB SmartIR, JB Cliente, entre outras —, o gestor do contrato ou um usuário do escritório responsável pela empresa precisará vincular esse usuário como um colaborador.

Para saber como realizar essa etapa, acesse as instruções de como vincular um colaborador.

Após a vínculação, o usuário também terá acesso ao wiki da JB Software. Nele é possível encontrar várias informações importantes.

# 3. Login no JB Network

- Para acessar (realizar login) o JB Network, é necessário clicar no botão "Acessar", que se localiza no canto superior direito do portal da JB Software. Indique seu e-mail adotado como login e a senha que foi confirmada.

# 4. Esqueceu sua senha?

- Caso não se lembre mais da sua senha, é possível fazer o processo de recuperação para cadastrar uma nova senha. Faça login no JB Network conforme explicado no item acima. Informe seu e-mail e, em seguida, clique no botão de recuperar a senha.



Um e-mail será enviado e nele há um link temporário para confirmar sua nova senha. Clique no link.



Ao clicar no link do e-mail, o usuário será redirecionado para o formulário 09885 - Criação/Alteração da senha de acesso para registrar e confirmar a nova senha. Digite seus dados e clique em salvar. Caso o usuário tenha o e-mail e a senha salvos no navegador, os dados serão preenchidos automaticamente.



# 5. Alterar dados pessoais

- O usuário pode realizar várias alterações do seu perfil pessoal. Para tal, basta acessar a "página do usuário", clicando no ícone indicado no canto esquerdo superior do JB Network, conforme imagem abaixo:



Veja informações sobre cada um dos formulários, clicando aqui.

Caso o usuário possua mais colaborações, ele pode selecionar em qual delas deseja logar; basta clicar sobre o nome do usuário. Então, serão listadas todas as empresas nas quais o usuário é colaborador.
