# Tabelas JBFolha

URL: https://wiki.jbsoft.com.br/tiki-index.php?page=Tabelas%20JBFolha

# TABELAS

Neste módulo o usuário tem total controle das tabelas de INSS, IRRF e códigos de municípios. É neste módulo onde se encontram também os códigos de FPAS, CNAE CBO entre outras, necessárias para o cálculo de folhas bem como para a geração de arquivos magnéticos.

# Códigos/classificações

- 03607-Cadastro de CNAE (Código Nacional de Atividade Econômica)

- 05335-Cadastro de grau de risco e percentual de RAT - CNAE

- 05036-Cadastro de CBOs

- 00012-Cadastro de municípios

- 05300-Tabela de Código Internacional de Doenças (CID)

- 03608-Cadastro de naturezas jurídicas

- 00011-Cadastro de UF

- 00010-Cadastro de países

- 03630-Cadastro de logradouros

# Verbas

- 05051-Tabela de verbas

- 05178-Cadastro de fórmulas para verbas

- 05342-Configuração de processos judiciais com incidências de verba

# Contribuições

- 05010-Tabela de INSS descontado do segurado, Salário-Família e FGTS

- 05021-Tabela do FPAS

- Tabelas do IRRF

- 05012-Tabela do IRRF/PIS folha de pagamento

- 05339-Tabela do IRRF para PLR

# Outras

- 05029-Tabela de faltas para determinação das férias

- 05224-Tabela de serviços

- 03606-Cadastro de índices
