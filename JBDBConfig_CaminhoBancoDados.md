# JBDBConfig -> Banco de dados-> Caminho do banco de dados

Permite configurar o caminho do banco principal e banco de logs, configurações avançadas e testes de conexão.

- Opções:

- Testar conexão: realiza um teste de conexão nos caminhos de banco de dados informados.

- Configurações avançadas: exibe as configurações avançadas referente ao arquivo de configuração de acesso ao banco de dados do sistema.

- Executar diagnóstico do sistema após teste de conexão: realiza uma validação de todos os pré-requisitos necessários para o funcionamento da aplicação da JB Software.
