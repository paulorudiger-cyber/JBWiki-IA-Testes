# JB Mobile

Aplicativo para alertas de comunicações das aplicações da JB Software.

O JB Mobile é uma aplicação para uso em dispositivos móveis que possui uma interface para recepção e gerenciamento dos alertas de mensagens que são postadas no módulo de Comunicação do JB Network, JB Cliente e JB Coml/Mkt.

Os alertas terão como origem qualquer comunicação realizada a exemplo:

- Escritório x Cliente

- Cliente x Escritório

- Franquia x Escritório

- Escritório x Franquia

- JB x Franquia

- JB x Cliente

Além de ser uma interface de gestão dos alertas, serve como ponte para acesso, pelo dispositivo móvel, a todas as aplicações Web da JB Software, onde podem ser inseridos, inclusive, comunicações para as aplicações, a exemplo de alteração salarial, aviso prévio, etc.
