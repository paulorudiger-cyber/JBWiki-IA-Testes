# JB Network

O JB Network é todo o ambiente on-line da empresa JB Software. Nele é possível agilizar a comunicação corporativa, manter documentos armazenados no site, baixar notas fiscais de forma automática, acessar todas estas informações com seu dispositivo móvel.
