# 1. S-2250 - Aviso Prévio

Este evento foi descontinuado a partir da versão S-1.0 do eSocial. 

As informações abaixo servem apenas para histórico de como era realizado no sistema enquanto o evento esteve vigente no eSocial. 

- Conceito do evento: 

Este evento tem como objetivo registrar a comunicação e o possível cancelamento do aviso prévio de iniciativa do empregador ou do empregado.

- Prazo:

- Este evento deve ser enviado em até 10 (dez) dias de sua comunicação.

- Conferência dos dados dos avisos prévios:

Ao efetuar o cadastro de um aviso pelo pacote 5284-Cadastro de aviso prévio, o próprio sistema já efetua as validações e emite mensagens de aviso, para evitar que faltem informações ao eSocial.

O pacote que precisa ser revisado é apenas o 5284 aba cadastro, e também clicando no botão Cancelar aviso prévio.

No arquivo abaixo são mostrados todos os campos enviados ao eSocial e os respectivos itens que precisam ser revisados.

- Informações para o evento S-2250.

    ESocial S 2250 Para Clientes

- Envio do evento de teste:

Antes de realizar o envio oficial, é possível realizar o envio para o ambiente de testes.

Antes de realizar o envio oficial, é altamente recomendável realizar o envio para o ambiente de testes.

Para isto, confira a forma de envio de testes em configurar ambiente para envio.

- Envio do evento para o ambiente oficial:

Depois disso pode-se realizar o envio do evento para o ambiente oficial.

Para realizar este processo, mude o ambiente para o oficial, se estiver usando o ambiente de teste, conforme descrito no item configurar ambiente para envio e, estando no pacote 5284, clique no botão eSocial. Ou, vá ao pacote 5283, aba 2-Não periódicos, informe o período (já virá atualizado com o período corrente - serão filtrados os avisos no período informado), a empresa e o(s) trabalhador(es) desejados. Escolha o evento S-2250 na grade e clique no botão Gerar.

- Observações:

- Para o aviso prévio indenizado não é necessário o envio deste evento.

- A recusa do empregado de comparecer ao trabalho durante o período do cumprimento do aviso prévio não altera o tipo de aviso, devendo os dias sem comparecimento serem considerados como faltosos.

- Caso uma das partes opte por cancelar o aviso e a outra concordar, o aviso prévio pode ser cancelado. O usuário pode efetuar o cadastro do cancelamento, e comunicar através do envio do S-2250 ao eSocial.

- Em caso de cumprimento parcial de aviso, não há necessidade de retificação do evento S–2250, pois o indicativo do cumprimento do aviso será enviado no evento S-2299-Desligamento.
