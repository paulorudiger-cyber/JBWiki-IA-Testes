# RELATÓRIOS

O módulo Relatórios do sistema JB Folha possui uma gama de relatórios que contemplam desde relatórios cadastrais até demostrações dos cálculos mensais, incluindo os relatórios da CAT e PPP.

Ainda dentro deste módulo é possivel fazer a impressão de guias de arrecadação de impostos bem como a geração de arquivos como GFIP, GRRF, CAGED, RAIS, DIRF, Manad para serem importados para seu respectivo programa validador.

Este módulo também possui relatórios que demonstram as compensações de INSS feitas e os valores ainda disponíveis e permite que o usuário mantenha um controle manual disto caso ele opte para que o sistema não faça isso automaticamente.
